# 1 HP · Aion 2 — дорожня карта 45 рівня

Статичний лендінг за інфографікою «Новачок 45 рівня — дорожня карта спорядження»:
чекліст прогресу, бойова міць із порогами розблокування, щоденні/щотижневі лічильники,
вбудована інтерактивна карта (interactivemap.app) і склад 1 HP.

Збірки немає — це чисті HTML/CSS/JS. Відкрийте `index.html` або викладіть папку на будь-який статичний хостинг
(Netlify, Cloudflare Pages: «publish directory» = `aion2-guide`).

**GitHub Pages:** workflow `.github/workflows/pages.yml` публікує сайт після злиття в `main`. Один раз увімкніть
*Settings → Pages → Build and deployment → Source: GitHub Actions*. Адреса: `https://<користувач>.github.io/<репозиторій>/`.
Для Discord-входу додайте цю адресу в *Site URL / Redirect URLs* у Supabase.

> Корінь репозиторію — окремий проєкт (WordPress-стартер на Next.js). Цей сайт від нього не залежить.

## Навігація і «Сьогодні»

- **Сьогодні** (перший розділ): головне на одному екрані — Розлом, найближчі боси (спершу з дзвіночком), ресети,
  запаси, що скоро заповняться, тижневі входи й ліміти, ваша група або кількість зборів, БМ і наступний поріг,
  останній пачноут (позначка «Новий!», доки його не відкрили). Кожна картка веде у свій розділ.
- **Перші кроки**: вхід через Discord, пошук персонажа, сповіщення, дзвіночки босів. Зникає, коли все зроблено,
  або кнопкою «Сховати».
- **Телефон**: нижня панель (Сьогодні, Персонаж, Таймери, Групи, Ще); «Ще» відкриває всі розділи. Активний розділ
  підсвічується і в нижній панелі, і у верхньому меню на комп'ютері. Кнопка «Нагору» з'являється після прокрутки.
- **Коротші розділи**: у таймерах 8 найближчих босів зони (кнопка «Показати всіх» запам'ятовується). У пачноутах
  на телефоні пояснення й «Виправлення» згорнуті. Глосарій і матриця карти на телефоні згорнуті до пошуку чи кнопки.
- **Повторний візит**: «Основні правила» згорнуті, обкладинка компактна.

## Мережа: діагностика пінгу і втрат пакетів

`netcheck/aion2-netcheck.ps1` — скрипт PowerShell для Windows (5.1 і 7), публікується разом із сайтом. Розділ
«Мережа» на сайті містить команду запуску з кнопкою копіювання. Скрипт не чіпає гру і не читає її пам'ять:

- знаходить TCP-з'єднання процесу гри (`-ProcessName`, за замовчуванням `aion`) і сервер (не порти 80/443);
- адаптер: кабель чи Wi-Fi, сигнал, помилки/відкинуті пакети, енергозбереження карти;
- `tracert` до сервера, потім одночасний ping роутера, кожного вузла, 1.1.1.1, 8.8.8.8 і сервера (`-Seconds`, 60);
- з правами адміністратора — повторні передачі саме на з'єднанні гри (Windows ESTATS);
- `-LoadTest` — пінг під навантаженням (bufferbloat);
- висновок, де починаються втрати (як pathping: справжня втрата тягнеться до кінця маршруту), звіт на Робочий стіл;
- `-ApplyTweaks` / `-Revert` — TcpAckFrequency і TCPNoDelay для активного адаптера та вимкнення енергозбереження
  мережевої карти, з резервною копією в `%LOCALAPPDATA%\1HP-netcheck`.

Файл збережено в UTF-8 з BOM: інакше Windows PowerShell 5.1 покаже кирилицю кракозябрами.

## Увімкнення входу через Discord (≈10 хвилин)

1. **Supabase**: створіть безкоштовний проєкт на <https://supabase.com>. У *SQL Editor* виконайте `schema.sql`.
2. **Discord**: <https://discord.com/developers/applications> → *New Application* → *OAuth2*.
   У *Redirects* додайте адресу зі сторінки Supabase: *Authentication → Providers → Discord* (виглядає як
   `https://<project>.supabase.co/auth/v1/callback`). Скопіюйте *Client ID* і *Client Secret*.
3. **Supabase → Authentication → Providers → Discord**: увімкніть, вставте Client ID / Secret.
4. **Supabase → Authentication → URL Configuration**: у *Site URL* і *Redirect URLs* вкажіть адресу, де лежить сайт
   (для локальної перевірки — також `http://localhost:8080/` тощо).
5. У `config.js` вкажіть `supabaseUrl` та `supabaseAnonKey` (*Project Settings → API → anon public*). Ключ публічний
   за задумом: доступ обмежують політики Row Level Security з `schema.sql` — кожен читає всіх, змінює лише себе.

Після входу прогрес автоматично зберігається (з паузою ~1 с), а розділ «Склад 1 HP» показує всіх учасників.
Видимі всім, хто увійшов: нік у Discord, аватар, бойова міць і відмітки дорожньої карти.

## Пошук персонажа за ніком («Підтягнути БМ»)

Кнопка з'являється, коли налаштовано Supabase. Вона викликає Edge Function `supabase/functions/aion-lookup`, яка:

1. шукає нік у регіонах NA East, NA West, EU, Asia, LatAm (точний збіг, без урахування регістру);
2. якщо персонажів кілька (однаковий нік на різних серверах) — показує список, щоб обрати свого;
3. бере профіль персонажа й записує в гайд **рівень предметів** (`ItemLevel` зі статів) як бойову міць.

Чому не поле `combatPower` з API: воно в десятки тисяч (напр. 71121 при рівні предметів 1353), а пороги гайда 1000–2800
відповідають саме рівню предметів (Gear Score): за ним, наприклад, відкривається рейд Лудри (≈2800). API-значення
показується поруч для довідки. Якщо потрібне інше поле, це змінюється в одному місці (`applyCharacter` в `app.js`).

Розгортання функції (потрібен [Supabase CLI](https://supabase.com/docs/guides/cli)), з папки `aion2-guide`:

```bash
supabase login
supabase functions deploy aion-lookup --project-ref <project-ref>
```

Окремих секретів не потрібно. Функція кешує відповіді на 10 хвилин і обмежує запити до 20 на хвилину з однієї IP.
Додатково виконайте оновлений `schema.sql` (додає колонку `character`).

**Джерело даних.** Це неофіційний доступ до тих самих ендпоінтів, що використовує сайт Aion 2
(`api-search.plaync.com/aion2global/…`, `aion2.plaync.com/api/character/info`). На порталі
[PlayNC Developers](https://developers.plaync.com) наразі є лише API для Lineage 2M і TimeTakers, тож офіційного
API Aion 2 немає. Адреси недокументовані й можуть змінитись або зникнути. Тоді кнопка покаже повідомлення, а бойову
міць можна ввести вручну. Коли з'явиться офіційне API, змінюється лише об'єкт `provider` у `index.ts`.

Обмеження за Discord-сервером (щоб бачили лише учасники 1 HP) тут не реалізовано: зараз увійти може будь-який
користувач Discord. Це можна додати через Supabase Edge Function, що перевіряє членство в гільдії.

## Склад 1 HP

Колонку «Оновлено» можна відсортувати: давно не оновлені записи (14 днів і більше) показуються червоним.
Кожен учасник змінює лише свій запис.

## Картка персонажа

Після «Підтягнути БМ» функція повертає повний знімок персонажа з сайту Aion 2, а розділ «Персонаж» показує:
профіль (клас, рівень, сервер, раса, титул), рівень предметів і бойову міць, усі 20 слотів спорядження з рідкістю й
заточкою, пета й крила, дошки Даеваніона (див. нижче), вміння з рівнями, характеристики, титули та скіни.

«Підказки за гайдом» рахуються зі спорядження: скільки рун екіпіровано, порожні слоти, заточка пояса й амулета
(ціль +10, потім Substance Morph), не жовте спорядження (його не точать, а замінюють) і жовте нижче +5.
Рідкості показано так, як у англійському клієнті: API віддає внутрішні назви (Legend = Epic, Epic = Heroic);
порядок Common < Rare < Epic < Unique (жовте) < Heroic. Кольори — як на офіційному сайті Aion 2:
білий, зелений, синій, жовто-золотий, помаранчевий. Знімок зберігається в колонці `members.game`, тож картку
будь-якого учасника можна відкрити зі складу 1 HP (клік по ніку). Дані оновлюються кнопкою «Оновити» та автоматично,
якщо їм більше 6 годин. Після оновлення функції її треба перерозгорнути, а `schema.sql` — виконати знову.

## Порівняння з білдом

У картці персонажа блок «Порівняння з білдом» показує, що підтягнути до обраного білду: наступні кроки, рівні
активних вмінь, стигм і пасивок «зараз → ціль», опції спеціалізації (номер і з якого рівня вміння відкривається).
Опції гра не віддає, тому виставлені відмічаються вручну.

- **Білди блогерів для всіх 8 класів**: кнопка «Обрати білд блогера» показує публічні білди вмінь з questlog.gg
  для класу вашого персонажа (позначка NC — офіційні від NCSOFT), з пошуком і сторінками. Запити йдуть через
  функцію `aion-lookup` (у questlog немає CORS). Обраний білд зберігається в профілі на цьому пристрої.
  Це неофіційний внутрішній API questlog.gg: якщо він зміниться, список перестане завантажуватись.
- **Вбудовані білди** (`data.js` → `builds`): зараз Cleric «The Silence of the Infernal Monster» з пріоритетами
  пасивок і порядком дошок Даеваніона. Новий білд — ще один об'єкт у `builds`.
- Регіони API: `nae`, `naw`, `eu`, `as` (Азія), `la` (Південна Америка).

## Дошки Даеваніона

У картці персонажа розділ «Дошки Даеваніона» показує кожну дошку так, як у грі: сітка 15×15, вузли в кольорах
рідкості, +рівні вмінь з іконками вмінь, відкриті вузли світяться, ті, що можна відкрити зараз, мають пунктирну рамку.
Натисніть вузол, щоб побачити ефект і шлях до нього (скільки вузлів відкрити дорогою).

- **Бонуси відкритих вузлів**: сума статів, PvP-статів і рівнів вмінь з усіх дошок.
- **Що відкрити далі**: закриті вузли, до яких можна дійти, за порядком гайда: активні вміння до 12 → цілі білду,
  з яким ви порівнюєте → помаранчеві атакувальні (Combat Speed, Cooldown Reduction, Damage Boost, Critical Damage
  Boost, Multi-Hit Chance) → вміння з білду → Attack і Critical Hit → захисні → решта; PvP і MP +50 — в кінці.
  Дальні цілі рахуються за середньою користю вузлів на шляху. Цифри на дошці — найкращі наступні вузли.
- **Зв'язок з білдом**: у «Наступних кроках» порівняння з'являється підказка, на якій дошці є +1 до потрібного
  вміння і за скільки вузлів.

Вузли приходять з окремого режиму функції `aion-lookup` (`{ daevanion: 1, characterId, serverId, region }`, по
одному запиту до сайту Aion 2 на кожну дошку, з кешем 10 хвилин). У базу вони не пишуться: власні дошки кешуються
в браузері на 6 годин і перечитуються після «Оновити», чужі (з картки учасника) завантажуються кнопкою
«Показати дошки». Після оновлення функцію треба перерозгорнути; `schema.sql` не змінювався.

## Пачноути

Розділ «Пачноути» показує офіційні пачноути Aion 2 Global українською: короткий підсумок, кожен пункт з перекладом,
поясненням «що це означає», позначками (на користь / обмеження / виправлення, для кого) і оригіналом англійською.
Блок «Для вашого персонажа» показує дії після останнього патча з урахуванням раси прив'язаного персонажа: пункти лише
для іншої раси притлумлені. Нові тижневі ліміти з патчів (морф Запечатаних Крил, Камені Воскресіння) — лічильники в
«Тижневих лімітах» розділу «Таймери»; вони не входять у суму тижневих входів.

- Переклади лежать у `data.js` → `patches` (новий пачноут — новий об'єкт зверху), ліміти — у `weeklyLimits`.
- Свіжі пачноути й оголошення сайт бере через `aion-lookup` (`{ news: 'list' }`, `{ news: 'article', board, id }`)
  з публічного API спільноти, яким користується сам сайт Aion 2. Пачноут без перекладу показується англійською
  з кнопкою «Показати текст тут». Після оновлення функцію треба перерозгорнути.
- **Посилання на пачноут**: кнопка «Скопіювати посилання» в картці. Для перекладених це коротка сторінка
  `guide.sulaslova.com/p/<articleId>/` з прев'ю для Discord (назва й підсумок), яку генерує
  `tools/patch-pages.mjs` під час публікації. Для решти посилання має вигляд `guide.sulaslova.com/#patch=<articleId>`.
  У поле над пачноутами можна вставити посилання з aion2.plaync.com: сайт відкриє переклад або текст англійською.

## Таймери

Розділ «Таймери» показує Розлом (Spacetime Rift), щоденний і щотижневий ресет та трекер польових босів.

- **Польові боси** (48: Вертерон і Альтгард) відроджуються через фіксований час після вбивства. Натисніть «Вбито» або
  «Раніше…», і почнеться відлік. Після входу через Discord відмітки спільні для всього складу 1 HP та
  оновлюються в реальному часі (таблиця `boss_kills`); без входу вони зберігаються в браузері. Дзвіночок вмикає
  сповіщення за 5 хвилин до відродження, поки сторінка відкрита.
- **Сповіщення** налаштовуються в розділі «Таймери»: за скільки хвилин попереджати (1–60 хв або свій час до 180),
  чи сповіщати ще й у момент появи боса / відкриття Розлому, та чи сповіщати про Розломи взагалі.
  Налаштування зберігаються в браузері кожного учасника.
- Цикли відродження й розклад Розлому для Global — **за даними гравців** (NCSOFT їх не публікував). Вони в
  `data.js` (`bosses`, `rift`): якщо в грі інакше, достатньо виправити число там.
- Боси Безодні (Решанта) не додані: їхній розклад для Global ще не підтверджено.

Для спільних відміток виконайте оновлений `schema.sql` (повторний запуск безпечний).

## Запаси, тижневі входи, збір у регіоні

- **Запаси й енергія** (розділ «Таймери»): введіть, скільки зараз Енергії Оділе (ліміт 560 або 840 з підпискою),
  нагород Підкорення, Трансценденції чи спроб Кошмару — сайт рахує, коли запас стане повним, і попереджає
  (галочка «Запаси» у «Сповіщеннях»). Поповнення для Global: Оділе +15/3 год, Підкорення +1/8 год (до 21),
  Трансценденція +1/12 год (до 14), Кошмар +2 щодня (до 14). Момент тіку в грі невідомий, тож це оцінка.
- **Тижневі входи**: Випробування Вознесіння, щоденне підземелля, квитки Приборкання (Subjugation), ключі Фестивалю
  Шуго, Дослідження кожного підземелля Експедицій. Скидаються в середу. У «Складі 1 HP» колонка «Тиждень» показує,
  скільки входів використав кожен учасник.
- **Збір у рідному регіоні**: Оплоти (15, по 2 сувої пояса) і Запечатані підземелля (61).

## Склад: рейтинг і готовність

«Рейтинг 1 HP» сортує учасників за рівнем предметів, показує зміну за 7 днів (таблиця `il_history`, поповнюється
при оновленні персонажа) і прогрес дошок Даеваніона. «Готовність до контенту» показує, хто вже дотягує до кожного
порогу, а також склад за класами.

## Збір групи

Розділ «Збір групи»: оголошення на Експедицію, рейд Лудри, Розлом тощо з часом, кількістю гравців і примітками.
Учасники записуються з роллю (танк, хіл, ДД, підтримка). Записаним приходить сповіщення перед стартом.
Потрібні вхід через Discord і оновлений `schema.sql` (таблиці `groups`, `group_members`).

## Сповіщення в Discord-канал

Функція `supabase/functions/discord-alerts` щохвилини перевіряє спільні відмітки босів, Розлом і групи та пише
в канал Discord: «бос відродиться через 5 хв», «Розлом відкривається», «новий збір групи», «скоро старт».
Час у повідомленнях Discord показує кожному в його часовому поясі. Працює й тоді, коли сайт ніхто не відкрив.

1. Discord: Налаштування каналу → Інтеграції → Вебхуки → Новий вебхук → «Копіювати URL вебхука».
2. Supabase → Edge Functions → Deploy a new function → Via Editor, назва `discord-alerts`, вставте
   `supabase/functions/discord-alerts/index.ts`, Deploy.
3. На сторінці функції → Secrets: додайте `DISCORD_WEBHOOK_URL` (URL з кроку 1). Необов'язково: `ALERT_LEAD_MIN`
   (5), `ALERT_MIN_CYCLE_MIN` (60 — сповіщати лише про босів з циклом від години, щоб не спамити),
   `ALERT_RIFT` (1 або 0), `ALERT_GROUP_LEAD_MIN` (15).
4. SQL Editor: виконайте `cron.sql` (вмикає щохвилинний запуск). Вимкнути: `select cron.unschedule('1hp-discord-alerts');`

Боси у функції — копія списку з `data.js`; якщо змінюєте цикли там, змініть і у функції.

## Англійські назви термінів

Гра на Global англійською, тому біля термінів у тексті гайда в дужках стоїть назва з англійського клієнта, а розділ
«Глосарій» містить повний список із пошуком. Перемикач «Англійські назви» під заголовком ховає їх. У `data.js`
термін записується як `[Оплоти|Strongholds]`. Назви звірено з англомовними гайдами та базами для Global
(Game8, Metabot, Aion 2 Maps, GameData Central, AION 2 Guides, Wikily).

## Ресет щоденних і щотижневих активностей

Лічильники скидаються за часом гри (Global): щодня о 07:00 UTC (16:00 за часом гри, UTC+9), щотижня в середу.
Значення задаються в `data.js` (`reset`). Під лічильниками показується час до найближчого ресету.

## Структура

- `data.js` — усі тексти гайда, етапи, пороги, зони карти (редагується без зміни логіки)
- `app.js` — чекбокси, профілі, імпорт/експорт, склад, карта
- `cloud.js` — Discord-вхід і синхронізація (Supabase)
- `supabase/functions/aion-lookup` — Edge Function для пошуку персонажа за ніком
- `supabase/functions/discord-alerts` — сповіщення в Discord (запускається з `cron.sql`)
- `schema.sql` — таблиця `members` + RLS
- `config.js` — ключі Supabase (порожні = локальний режим)
