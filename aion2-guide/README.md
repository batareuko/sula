# 1 HP · Aion 2 — дорожня карта 45 рівня

Статичний лендінг за інфографікою «Новачок 45 рівня — дорожня карта спорядження»:
чекліст прогресу, бойова міць із порогами розблокування, щоденні/щотижневі лічильники,
вбудована інтерактивна карта (interactivemap.app) і склад 1 HP.

Збірки немає — це чисті HTML/CSS/JS. Відкрийте `index.html` або викладіть папку на будь-який статичний хостинг
(GitHub Pages, Netlify, Cloudflare Pages: «publish directory» = `aion2-guide`).

> Корінь репозиторію — окремий проєкт (WordPress-стартер на Next.js). Цей сайт від нього не залежить.

## Режими роботи

| Режим | Що потрібно | Де зберігається прогрес |
| --- | --- | --- |
| Локальний (за замовчуванням) | нічого | `localStorage` браузера; обмін між учасниками через «посилання» профілю та імпорт |
| Discord | Supabase + Discord-застосунок (нижче) | у базі Supabase; усі, хто увійшов, бачать склад 1 HP |

## Увімкнення входу через Discord (≈10 хвилин)

1. **Supabase**: створіть безкоштовний проєкт на <https://supabase.com>. У *SQL Editor* виконайте `schema.sql`.
2. **Discord**: <https://discord.com/developers/applications> → *New Application* → *OAuth2*.
   У *Redirects* додайте адресу зі сторінки Supabase: *Authentication → Providers → Discord* (виглядає як
   `https://<project>.supabase.co/auth/v1/callback`). Скопіюйте *Client ID* і *Client Secret*.
3. **Supabase → Authentication → Providers → Discord**: увімкніть, вставте Client ID / Secret.
4. **Supabase → Authentication → URL Configuration**: у *Site URL* і *Redirect URLs* вкажіть адресу, де лежить сайт
   (для локальної перевірки — також `http://localhost:8080/` тощо).
5. У `config.js` вкажіть `supabaseUrl` та `supabaseAnonKey` (*Project Settings → API → anon public*). Ключ публічний
   за задумом: доступ обмежують політики Row Level Security з `schema.sql` — кожен читає всіх, змінює лише себе.

Після входу прогрес автоматично зберігається (з паузою ~1 с), а розділ «Склад 1 HP» показує всіх учасників.
Видимі всім, хто увійшов: нік у Discord, аватар, бойова міць і відмітки дорожньої карти.

Обмеження за Discord-сервером (щоб бачили лише учасники 1 HP) тут не реалізовано: зараз увійти може будь-який
користувач Discord. Це можна додати через Supabase Edge Function, що перевіряє членство в гільдії.

## Структура

- `data.js` — усі тексти гайда, етапи, пороги, зони карти (редагується без зміни логіки)
- `app.js` — чекбокси, профілі, імпорт/експорт, склад, карта
- `cloud.js` — Discord-вхід і синхронізація (Supabase)
- `schema.sql` — таблиця `members` + RLS
- `config.js` — ключі Supabase (порожні = локальний режим)

## Нотатки

- Карта — iframe зі стороннього сайту; українська версія в нього відсутня, тому показано англійську.
  Зони: Вертерон, Альтгард, Елтнен, Морхайм.
- Лічильники «щодня / щотижня» скидаються за локальним часом користувача (00:00, понеділок);
  фактичний ігровий ресет може відрізнятись.
